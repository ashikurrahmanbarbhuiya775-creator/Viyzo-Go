# Viyzo AI Media Studio (isolated demo)

This folder is intentionally separate from the existing Viyzo Go Android application files.

## Open
Open `index.html` in a modern browser, or serve this folder with any static HTTP server.

## Current scope
- Private-workspace style dashboard UI
- Video prompt form (country, language, duration, fictional presenter / voiceover)
- In-browser demo project list
- Automatic production and post-production pipeline preview
- Supervisor engine status panel
- Publishing safety gate: explicit owner approval is required

## Important limitations
This is a front-end demo only. It does not call AI providers, generate real scripts/audio/images/videos, edit media files, upload to storage, or publish to social platforms. All engines are shown as not connected. No credentials or paid services are used.

## Isolation
No existing Android app files, website files, Gradle settings, or shared backend configuration are modified by this demo.
